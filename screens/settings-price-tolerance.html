How this is applied
Where these thresholds show up across the product.
Sloan · Governance agent
When a supplier price file comes in, Sloan checks each change against the category (or SKU) tolerance before proposing it to the market list — movements within tolerance are pre-cleared, the rest are flagged for review. See it in action on the market list price change banner.
Cyrus · Invoice agent
During 3-way match, an invoiced unit price above market list is only raised as a price exception once it exceeds the item's tolerance — small, expected movement no longer creates noise in the exceptions queue.
Reporting & exceptions
Price exception tables in Reporting use these same thresholds, so what counts as "in tolerance" stays consistent between the agents and what HQ reviews.
