How this is applied
Where these windows and zones show up across the product.
Time windows
Every zone's "Window" field is chosen from this list. Adding a window makes it selectable everywhere; editing one's start/end time updates every zone using it immediately, without needing to re-pick it.
New order
When an outlet orders from this Central Kitchen, the next available delivery date is computed from its zone's days and cutoff — the same way an external supplier's delivery schedule works today.
Customers
The delivery schedule shown on each outlet in Customers reflects its current zone assignment.
Fulfilment
Dispatch runs in Fulfilment are grouped by the same time windows defined here, so a zone change reshapes tomorrow's picking runs immediately.
