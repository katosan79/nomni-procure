What happens next
Recipes are imported as drafts. They will not be published or assigned to any outlets automatically. After importing, go to each recipe and assign it to the relevant outlet groups, then publish.
Ingredient lists are not included in the CSV import — you'll need to add ingredients to each recipe manually after importing. Selling prices and target FC% will be set from the file where provided.
This import will be logged in the activity timeline with your name, timestamp, and the number of records affected.
