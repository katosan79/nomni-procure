---
title: Roles & Permissions
description: Who can see and do what in Nomni Procure.
---

Nomni has six built-in roles. Each role is a template over a permission engine of 200+ discrete permissions, enforced at the API layer. Scope is set per outlet group — a user can be an HQ Admin for one brand and an Outlet Manager for another.

## Role overview

| Role | Manages | Can approve orders | Sees all outlets |
|---|---|---|---|
| **HQ Administrator** | Full platform: market lists, recipes, POS, users, suppliers, reporting | Yes | Yes |
| **HQ Approver** | Review and approve orders, recipes, POS mappings; view-only on admin | Yes | Yes |
| **Outlet Manager** | Raise requisitions, receive goods, manage stock counts | Up to threshold | Own outlet only |
| **Outlet User** | Raise requisitions, receive goods, run stock counts | No | Own outlet only |
| **Finance User** | Invoice management, 3-way match, Xero export, reporting | No | View-only |
| **Supplier User** | Nomni Supply portal — view orders, submit e-invoices, manage catalogue | N/A | N/A |

## What each role sees in the nav

| Module | HQ Admin | HQ Approver | Outlet Manager | Outlet User | Finance |
|---|---|---|---|---|---|
| Dashboard | Full cross-outlet | Full cross-outlet | Own outlet | Own outlet | Finance view |
| Orders | All outlets | All outlets | Own outlet | Own outlet | View-only |
| Invoices | ✓ | View-only | — | — | Full access |
| Items | Full CRUD | View-only | View-only | View-only | — |
| Inventory | Full | Full | Full | Limited | — |
| Market lists | Full CRUD | View + approve | Read-only | — | — |
| Recipes | Full CRUD | View + approve | Read-only | Read-only | — |
| POS mapping | Full (config + monitor) | View-only | — | — | — |
| Reporting | Full | Full | Own outlet | — | Full |
| Outlets | Full CRUD | View-only | Own outlet | — | — |
| Suppliers | Full CRUD | View-only | — | — | View-only |
| Users | Full CRUD | — | — | — | — |

## HQ-locked content

When HQ publishes a recipe, market list, or POS mapping to an outlet, that content is **locked** at the outlet level. Outlet users will see a banner: "Managed by HQ — this can't be edited here." Only an HQ Admin can unlock or override.

## Switching roles (prototype)

The prototype includes a role switcher in the top bar so you can see how the interface changes for each role without logging out. This is a prototype-only feature — production uses real authentication and session-scoped permissions.

## Managing users

HQ Administrators can add and manage users from **Settings → Users**. Assign roles per outlet group — a user can hold different roles across different groups.

<Warning>
Removing a user does not delete their activity history. All past actions remain in the audit log.
</Warning>
