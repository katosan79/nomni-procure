## Count types

| Type | When to use | Time required |
|---|---|---|
| **Full count** | Weekly or monthly — every item in every storage location | 2–4 hours |
| **Category count** | Mid-week spot-check on a high-cost category (e.g. proteins) | 30–60 mins |
| **Spot count** | Single item check — quick reconciliation after a delivery | Under 5 mins |

## Count templates

Count templates define which items appear on a count sheet and in what order. HQ Admins create templates in **Inventory → Governance → Count templates**. Templates are assigned to outlet groups and can be locked (outlets can't modify the item list).

A good template groups items by storage location (cool room, dry store, freezer, bar), not by category — it's faster for counting staff to work through a physical space than to skip around by category.

## Tips for accurate counts

**Before counting:**
- Freeze stock movements. No deliveries or production runs should happen during a count.
- Print the count sheet or use the mobile interface — don't rely on memory.

**During counting:**
- Count to the base UOM (kg, L, each) — don't round.
- For items sold by the unit but ordered by the case, count in units and enter the conversion.
- If you find an item that's not on the count sheet, add it as a new entry and flag it for review.

**After counting:**
- Review high-variance items before submitting. A −20kg variance on chicken is worth double-checking before it hits the report.
- Submit on the same day the count was taken. Don't backdate.

## The count sheet

The count sheet shows:

| Column | Description |
|---|---|
| Item name | Your buyer name (not the supplier SKU) |
| UOM | The unit you're counting in |
| Last count | Quantity from the previous count |
| Expected (theoretical) | What the system expects based on purchases and sales |
| Actual | The quantity you enter |
| Variance | Calculated automatically after submission |

<Warning>
The "Expected" quantity is a guide, not a target. Don't adjust your count to match it — that defeats the purpose of counting.
</Warning>
