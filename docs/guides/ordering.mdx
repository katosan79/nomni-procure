## How ordering works

Every purchase order in Nomni follows the same lifecycle:

```
Draft → Submitted → Pending Approval (if required) → Approved → Sent to Supplier → Delivered → Closed
```

Orders are always raised against a specific **outlet** and **supplier**. A single order can only have one supplier — if you need items from multiple suppliers, raise separate orders.

## Raising an order

<Steps>
  <Step title="Open New Order">
    Go to **Orders → New order**. Select the outlet you're ordering for.
  </Step>
  <Step title="Choose a supplier">
    Select the supplier from the dropdown. Only suppliers linked to the selected outlet will appear.
  </Step>
  <Step title="Add line items">
    Items that have a par level set will appear pre-suggested with a recommended quantity (based on current stock vs par). You can:
    - Accept the suggestion
    - Adjust the quantity manually
    - Add additional items from the catalogue
    - Remove items you don't need this order
  </Step>
  <Step title="Set delivery details">
    Enter the expected delivery date. Add any supplier notes in the comments field.
  </Step>
  <Step title="Submit">
    Click **Submit order**. If your group requires HQ approval for orders above a threshold, the order enters **Pending Approval** state.
  </Step>
</Steps>

## Approval thresholds

HQ Administrators can set an approval threshold per outlet group. Orders below the threshold are auto-approved. Orders at or above it route to an HQ Approver.

<Info>
Auto-approved orders are still logged in the activity timeline. Nothing is silently processed.
</Info>

## Order statuses

| Status | Meaning |
|---|---|
| **Draft** | Started but not submitted |
| **Pending Approval** | Awaiting HQ sign-off |
| **Approved** | Approved, awaiting dispatch to supplier |
| **Sent** | Transmitted to supplier |
| **Partially Delivered** | Some items received, order still open |
| **Delivered** | All items received, GRN complete |
| **Closed** | Matched against invoice, closed out |
| **Cancelled** | Voided before delivery |

## The agent-suggested order

If the **Ordering Agent** (Otto) is enabled for your group, it will draft orders automatically based on par levels and current stock. You'll see these appear as suggested orders in **Orders** with an "Agent draft" badge.

You review the draft, adjust quantities if needed, and approve. The agent never submits an order without a human reviewing it first.

## Receiving a delivery

Once goods arrive, open the order and click **Receive delivery**. Record the actual quantity received per line item. Any shortfall or overage is noted as a discrepancy and flags to Finance for invoice matching.
