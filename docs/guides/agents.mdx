Nomni has five AI agents that handle routine analysis and surface recommendations. They act on your behalf — but never without your review. Every agent suggestion requires a human to approve before anything changes.

## How they show up

Agent suggestions appear as **cards** on the relevant screen — never as pop-ups or interruptions. Each card shows:

- Which agent is making the suggestion
- What they're recommending and why
- The confidence level
- Action buttons (Approve / See alternatives / Dismiss)

Agent-touched content gets a subtle **green border and glow** so you can see at a glance what's been AI-suggested vs manually entered.

## Otto — Ordering Agent

Otto monitors par levels and current stock across all outlets. When stock falls below par, it drafts a suggested order.

**What Otto does:**
- Calculates fill-to-par quantities per item
- Selects the preferred supplier for each item
- Groups items by supplier into draft orders
- Respects lead times and delivery day schedules

**What Otto never does:**
- Submit an order without human approval
- Switch preferred suppliers without your instruction
- Order items that don't have a par level set

If Otto drafts an order, it appears in **Orders** with an "Agent draft" badge. Review it, adjust quantities if needed, and approve.

## Vera — Variance Agent

Vera runs after each stock count is submitted. It compares actual stock against theoretical (what the recipes and POS sales say you should have).

**What Vera surfaces:**
- Items with variance above your configured tolerance
- Likely causes (e.g. "GRN not recorded for Order #1234")
- Historical patterns (e.g. "Chicken Breast consistently over-counted on Thursdays")

## Sloan — Governance Agent

Sloan handles the operational governance tasks that would otherwise fall on an HQ Admin manually.

**What Sloan does:**
- Suggests POS mappings for newly synced items with no match
- Flags supplier price file changes for HQ review before they're pushed
- Drafts market list updates when new supplier catalogues are ingested

## Mara — Invoice Agent

Mara extracts structured data from uploaded invoices and runs the 3-way match automatically.

**What Mara does:**
- OCR extraction of supplier name, invoice number, date, line items, totals
- 3-way match against PO and GRN
- Flags discrepancies (price, quantity, items not on PO)
- Queues matched invoices for Xero export

## Cyrus — Margin Agent

Cyrus watches for recipe margin changes triggered by supplier price movements.

**What Cyrus does:**
- Recalculates recipe costs when a new invoice price is recorded
- Alerts when a recipe's food cost % crosses your configured threshold
- Surfaces three options: reprice the menu item, find a cheaper supplier, or modify the recipe

## Turning agents on or off

Each agent can be toggled per outlet group in **Settings → Agents**. Agents are on by default for new groups. You can also set per-agent thresholds — for example, Otto can be set to auto-approve orders under $200 without requiring manual review.

<Warning>
Auto-approve is off by default. Enable it only after you've reviewed several agent-drafted orders and are confident in the quality.
</Warning>
