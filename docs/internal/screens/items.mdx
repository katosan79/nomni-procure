## items.html

**Canvas:** `data-measure="content"` (1080px)

### Summary strip

| Metric | Value |
|---|---|
| Total items | 188 |
| Supplier linked | 161 (86%) |
| Need attention | 27 (no preferred supplier) |
| Added this month | 14 |

### Category grid

6 category cards: Produce (47) · Protein (31) · Dairy (18) · Dry goods & Bakery (58) · Beverages (22) · Cleaning & Supplies (12). Each card shows item count and supplier coverage %. Clicking navigates to the list view filtered to that category.

### List view columns

Item name · Category · UOM · Linked suppliers (preferred chip + "+N" overflow) · Recipes (count) · Assigned groups · Last updated · Actions

**Every row is clickable** → opens the item detail drawer.

### Item detail drawer

Width: 460px.

Fields:
- `internalId`, `buyerName`, category, UOM, sub-category (optional), description (optional)
- **Supplier SKU table:** Supplier · Their SKU (IBM Plex Mono) · Order in (pack) · Conv. factor · Last cost · Preferred (radio — one per outlet group)
- **Par levels per outlet group:** inline number inputs (one row per group)
- **Linked recipes:** expandable accordion — recipe name, qty used, link to recipe detail

Footer actions: Edit item · Manage suppliers

### Row overflow menu

Edit item · Manage suppliers · **Remove item** (destructive — shows downstream impact modal: N recipes, N open orders, N outlet groups before confirming)

### Endpoints

- `GET /items?category&status&search` — paginated
- `GET /items/:id` — detail with SKU links, par levels, linked recipes
- `DELETE /items/:id` — requires `{ "acknowledgement": { "recipeCount": N, "orderCount": N, "groupCount": N } }` in body

## new-item.html

4-step wizard.

### Step 1 — Define item

Required: Buyer name · Category · UOM  
Optional: Sub-category · Description

### Step 2 — Link suppliers

Inline-editable table. Columns: Supplier (dropdown) · Their SKU · Order in · Conv. factor · Last cost · Preferred (toggle)

"Skip for now" allowed — item can exist without supplier links.

### Step 3 — Par levels

One row per outlet group (NSW Metro, VIC Metro, QLD Metro, SA Metro). Number input per group.

"Skip & create item" allowed.

### Step 4 — Done

Confirmation card: Name · Category · UOM · Suppliers linked (count)

### Endpoint

`POST /items` with `{ buyerName, category, uom, subCategory?, description?, supplierSkuLinks?: [...], parLevels?: [...] }`

## Bulk import

`POST /items/import` — multipart upload of `.xlsx`.

Template: Download via `GET /items/import/template`.

Required columns: Buyer name · Category · UOM  
Optional columns: Sub-category · Description · Supplier name · Supplier SKU · Order in · Conv. factor · Last cost

Validation errors returned per row. Import is transactional — all succeed or all fail.
