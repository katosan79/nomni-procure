### Table columns

Invoice # (IBM Plex Mono) · Supplier · Date · Total (AUD) · PO # · Status pill · Source icon (upload / portal / PEPPOL / manual) · Match score

## invoice-detail.html

### Header

Invoice number · Supplier · Invoice date · Total · Status pill · Source

### 3-way match panel

Three-column view: Purchase Order · Goods Receipt · Invoice

Per line: item name, qty, unit price, line total. Discrepancies highlighted in amber (price) or red (qty).

Match summary: X of Y lines matched · Price variance: $N · Qty variance: N units

### Approve / Dispute actions

| State | Available actions |
|---|---|
| needs_review | Approve · Dispute (with reason) |
| partially_matched | Approve with exceptions · Dispute |
| matched | Approve · Dispute |
| approved | Export to Xero · Mark as paid |
| disputed | Resolve dispute · Reject invoice |

### Activity timeline

Invoice receipt → OCR extraction → match attempt → any manual edits → approval → export.

### Endpoints

- `GET /invoices/:id` — with lines and match result
- `PATCH /invoices/:id/approve`
- `PATCH /invoices/:id/dispute` — requires `{ "reason": "..." }`
- `POST /invoices/:id/export-xero`
- `PATCH /invoices/:id/mark-paid`

### Mara agent surface

If Mara's OCR confidence is below threshold on any line, a yellow banner appears: "Some fields need review — extracted data may be inaccurate." Affected fields are highlighted. User can correct inline before approving.
