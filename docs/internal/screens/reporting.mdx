## reporting.html

**Canvas:** `data-measure="wide"` (1280px)

**Access:** HQ Admin · HQ Approver · Finance · Outlet Manager (own outlet only)

---

## Filter bar (global, affects all sections)

- Date range (preset: This week / This month / Last month / Custom)
- Outlet group
- Outlet
- Category (food / beverage / supply)

All chart and table sections respond to filter changes simultaneously.

---

## Sections

### Revenue & food cost

Line/area chart: revenue vs food cost $ over the selected period. Overlay: food cost % line. Filter by outlet or group.

### Top spend items

Ranked list (top 20): Item name · Category · Total spend · % of total COGS · Trend chip.

### Supplier spend

Table: Supplier · Total spend · Order count · Average order value · YoY change.

**"Full breakdown →" link** in the chart card header navigates to `spend-by-supplier.html`.

### Variance summary

Table: Item · Theoretical usage · Actual usage · Variance · Variance % · Trend. Sorted by variance % descending. Colour-coded: within tolerance = green, outside = red.

### Order activity

Table: Period · Orders raised · Total value · Avg approval time · Rejection rate.

### Invoice reconciliation

Table: Total invoices · Matched · Partially matched · Unmatched · Disputed · Avg days to match.

---

## Data completeness checklist

Sidebar or banner (when any score is low):

| Signal | Good | Warning |
|---|---|---|
| POS mapping coverage | ≥90% | <90% |
| GRN completeness | ≥95% of orders have a GRN | <95% |
| Count frequency | All outlets counted in last 7 days | Any outlet >14 days |
| Invoice reconciliation | <5 unmatched | ≥5 unmatched |

## spend-by-supplier.html

**Canvas:** `data-measure="content"` (1080px)

**Access:** HQ Admin · HQ Approver · Finance · Outlet Manager (own outlet only)

**Entry point:** "Full breakdown →" link on the Spend by supplier card in `reporting.html`.

### Controls
- **Period picker:** Segmented button group — Last 30d / This month / Last quarter / YTD / Custom. Active: `background: var(--seaweed); color: var(--cream)`. Custom reveals two `<input type="date">` fields.
- **Outlet filter:** `<select>` — "All outlets (124)" default.

### KPI strip (4 tiles)
Total spend · Avg order value · Active suppliers · Spend concentration (top 3 suppliers as % of total)

### Spend concentration bar
Flex container, `height: 36px`, proportional-width segments per supplier, each `onclick` navigates to supplier detail. Hover: `filter: brightness(0.88)`.

### Supplier table
Columns: Supplier (avatar + name + category tag + primary/secondary badge) · Spend · Orders · Avg order · vs Prior period (delta chip) · On-time delivery (bar + %) · 6-month trend (SVG sparkline 80×28px) · View link (hover-reveal).

Full row is clickable → `supplier-spend-detail.html?s=slug`.

### Endpoints
- `GET /reporting/supplier-spend?period=&outletId=` → supplier list with spend, orders, avg order, delta, delivery rate, sparkline data

## supplier-spend-detail.html

**Canvas:** `data-measure="content"` (1080px)

**Access:** Same as reporting

**URL routing:** `?s=slug` resolved client-side via `SUPPLIERS` JS map. Default: `harbour-meats`.

### Controls
Same period picker and outlet filter as `spend-by-supplier.html`.

### KPI strip (5 tiles)
Spend this period · Prior period · Orders · Avg order value · On-time delivery

### Tabs
Overview (active) · Orders (stub) · Items (stub)

### Exception callout
Shown when `priceExceptions.length > 0`. Background: `var(--status-risk-bg)`. Lists affected items with invoiced vs market list price and variance %. "View in price exceptions →" link.

### Monthly spend chart
SVG `viewBox="0 0 600 190"`. Formula: `y = 150 - (val/30) * 120`. Confirmed months: solid polyline + filled dots. Current MTD: dashed line + open circle. Value labels: `font-size="10"`. Axis labels: `font-size="13"`. Area fill: `linearGradient` `#17B3A3` 18%→0%.

### Spend by outlet panel
Bar list — top 6 outlets + "Others (N)". Values: outlet name · proportional bar · spend $.

### Top items by spend panel
Bar list — top 6 items. Exception items show amber "exception" badge.

### Recent orders table
Columns: Order # · Date · Outlets · Items · Total · Status. Row → order detail. "View all N →" panel header link.

### Endpoints
- `GET /reporting/supplier-spend/:supplierId?period=&outletId=` → KPIs, monthly series, outlet breakdown, top items, recent orders, price exceptions

## Endpoints

All reporting endpoints accept the same filter params: `outletId`, `groupId`, `dateFrom`, `dateTo`, `category`.

- `GET /reporting/revenue-and-food-cost`
- `GET /reporting/top-spend-items`
- `GET /reporting/supplier-spend`
- `GET /reporting/variance`
- `GET /reporting/order-activity`
- `GET /reporting/invoice-reconciliation`
- `GET /reporting/data-completeness`

All endpoints are read-only. No mutations from the reporting screen.

## Performance note

Reporting endpoints should be backed by a pre-aggregated reporting table updated on a schedule (nightly + on-demand after significant events: GRN submitted, invoice approved, stock count submitted). Real-time calculation across 124 outlets is not feasible at query time.
