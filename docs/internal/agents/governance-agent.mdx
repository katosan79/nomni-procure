## What Sloan does

Sloan handles the HQ-level governance tasks that would otherwise require manual intervention: ingesting supplier price files, suggesting POS item mappings, and drafting market list updates.

## Triggers

| Trigger | Action |
|---|---|
| Price file uploaded | Extract structured data, diff against current market list, draft update for HQ review |
| POS sync completed | Find unmatched PosItems, suggest mappings with confidence scores |
| Schedule (weekly) | Audit POS coverage across all outlets, flag gaps to HQ |

## POS mapping suggestions

After each POS sync, Sloan scans for `PosItem` rows with no `PosMapping`. For each:

1. Fuzzy match `PosItem.name` against `Recipe.name` and `InternalItem.buyerName`
2. Score the match (name similarity × category alignment × outlet context)
3. If confidence ≥ 0.7: create a `PosMapping` with `mappedBy = 'agent_suggested'`
4. Surface suggestion card in the POS Configuration screen

The suggestion card shows:
- Matched POS item name
- Proposed target (recipe or item)
- Confidence score
- How many outlets this mapping would apply to

Actions: **Approve mapping** · **See alternatives** · **Dismiss**

Approved mappings update `mappedBy = 'agent_approved'`. Dismissed mappings set a `dismissedAt` timestamp and won't resurface for 30 days.

## Market list price file ingestion

When an HQ Admin uploads a supplier price file (Excel, CSV):

1. Sloan extracts line items and normalises to `{ supplierSku, unitPrice, effectiveDate }`
2. Diff against the current approved `MarketListLine` costs
3. For each changed item: create a `PriceChangeSuggestion` record
4. Surface a batch approval card: "N price changes from Supplier X — review before pushing"

Sloan never updates market list costs directly — always requires HQ approval.

## Emits

```typescript
{
  type: 'market_list.propagated',
  draftId,
  outletId,
  changesApplied,
  propagatedAt
}
```

## HQ-only

Sloan does not run for Standalone outlets. In Hybrid mode, Sloan runs for HQ-governed items only — local exception items are flagged as conflicts in the suggestion review UI.
