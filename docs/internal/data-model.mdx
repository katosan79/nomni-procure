## Entity map

```
Organisation
  └── Brand
        └── Region
              └── OutletGroup (operating mode: HQ | Hybrid | Standalone)
                    └── Outlet

InternalItem  ────────────────────────────────────────────┐
  └── SupplierSkuLink → Supplier                          │
  └── ParLevel → OutletGroup                              │
  └── RecipeIngredient → Recipe                           │
  └── PosMapping → PosItem                                │
                                                          │
PurchaseOrder → Outlet, Supplier                          │
  └── PurchaseOrderLine → InternalItem ←─────────────────┘
        └── GoodsReceiptLine

Invoice → Supplier, PurchaseOrder
  └── InvoiceLine → InternalItem

Recipe → Brand (locked flag)
  └── RecipeIngredient → InternalItem (or Recipe for sub-recipes)

StockCount → Outlet
  └── StockCountLine → InternalItem

PosItem → Outlet (from POS sync)
  └── PosMapping → InternalItem or Recipe

MarketList → OutletGroup
  └── MarketListLine → InternalItem, Supplier, price
```

## Core entities

### InternalItem

The buyer's canonical item definition. **Join key across the entire platform** — never join via `supplierSku`.

| Field | Type | Notes |
|---|---|---|
| `internalItemId` | UUID | Primary key |
| `buyerName` | string | e.g. "Chicken Breast 500g" |
| `category` | enum | Produce, Protein, Dairy, Dry goods & Bakery, Beverages, Cleaning & Supplies |
| `uom` | enum | kg, g, lb, L, mL, each, dozen, portion, serve, loaf, bottle, can, carton, bag, box, case |
| `subCategory` | string? | Optional |
| `description` | string? | Optional |

### SupplierSkuLink

Links an `InternalItem` to a supplier-specific SKU. One item can have multiple links.

| Field | Type | Notes |
|---|---|---|
| `internalItemId` | FK | → InternalItem |
| `supplierId` | FK | → Supplier |
| `supplierSku` | string | Shown in IBM Plex Mono throughout UI |
| `orderIn` | string | Pack size (e.g. "5kg carton") |
| `conversionFactor` | decimal | Multiply pack qty to get buyer UOM qty |
| `lastCost` | decimal | Updated on every invoice receipt |
| `isPreferred` | boolean | One preferred per item per outlet group |

## Key business rules

1. **Buyer-primary join** — all cross-entity joins use `internalItemId`, never `supplierSku`
2. **Weighted average cost** — `InternalItem.lastCost` is a weighted average computed from recent invoices by the Invoice Agent
3. **Preferred supplier** — `SupplierSkuLink.isPreferred` is scoped per outlet group, not globally
4. **Recipe lock** — `Recipe.lockedByHq = true` hides all edit controls at outlet level (not just disables)
5. **Push does not affect in-flight orders** — market list price pushes must not update `PurchaseOrderLine.orderedUnitCost` on open orders
6. **POS config in outlet settings** — POS connection credentials and configuration live on the `Outlet` entity, not in the PosMapping table
